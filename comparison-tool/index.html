About these ratings & the affordance scale

These are qualitative affordances drawn from the survey's prose — a sense of what each medium is like to work with — not lab benchmarks. Think of it the way a painter weighs oil vs. watercolor, not a spec sheet.

Each scored axis runs 0–3:

  • Ambient light 0 needs darkness → 3 readable in sunlight
  • Scale 0 handheld → 3 architectural
  • Resolution 0 blocky/points → 3 sharp
  • Motion 0 static → 3 full video / high refresh
  • Transparency 0 opaque → 3 see-through / floats in air
  • Cost 0 DIY/cheap → 3 premium / six-figure+
  • Safety 0 hazardous/licensed → 3 inherently safe

A dash (—) means the source text doesn't say — an honest gap, not a zero. Every rating links back to the section it came from, so you can check it. Spot something wrong? Corrections via PR or issue are welcome.

Status tags: comparable means you could realistically choose and deploy it today; borderline means the technology is real but pre-commercial, one-off, or niche — treat its ratings as more provisional.

On sorting: equal dots mean the same tier. Ties are broken by rating confidence then name — so the left-to-right order inside a band is not a finer ranking.
